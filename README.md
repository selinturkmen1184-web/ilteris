# ilteris.com.tr

“Üret. Paylaş. Öğren. Anonim Kal.”

Anonim teknoloji topluluğu için hazırlanmış, mobil uyumlu ve etkileşimli ürün prototipi. Ana sayfa, merkezi arama ve filtreleme, proje/blog/gönderi akışları, içerik ayrıntıları, anonim profil ve sayısal ID, raporlama, dosya ve harici bağlantı uyarıları, tema/dil/animasyon tercihleri ile ayrı yönetim paneli demosunu içerir.

## Çalıştırma

```bash
npm install
npm run dev
```

## Derleme

```bash
npm run build
npm run pages:build
```

`npm run pages:build`, GitHub Pages için statik çıktıyı `pages-dist/` klasöründe oluşturur.

## Önemli mimari not

GitHub Pages yalnızca statik dosya barındırır. Bu sürümde tercihler, oluşturulan örnek içerikler ve yorum limiti tarayıcıda yerel olarak çalışır. Gerçek kullanıcı kayıtları, benzersiz ID garantisi, kalıcı içerik/dosya yükleme, yetkilendirme, kötüye kullanım kayıtları, antivirüs taraması ve moderasyon işlemleri için güvenli bir sunucu uygulaması ve veritabanı gerekir.
